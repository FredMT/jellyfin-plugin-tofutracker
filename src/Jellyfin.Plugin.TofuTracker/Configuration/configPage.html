TofuTracker

Help

Sends what each linked Jellyfin user plays to their own TofuTracker library. Movies and TV episodes only, and only titles that have provider ids (IMDb, TMDb, TVDB, ...).

Leave the default unless you run your own scrobbler. Must be https (http only for localhost).

Jellyfin users

Click Link for a user, then give them the code. They open the link, sign in to TofuTracker and approve it. Each user links their own account.
